# Rock Paper Scissors
A browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/lessons/foundations-revisiting-rock-paper-scissors) foundations course.
## Live Demo
[View it live](https://nathanjspriegel.github.io/rock-paper-scissors/)
## What I practiced
- Refactoring a console/prompt-based game into a click-driven UI
- Updating the DOM with `textContent` instead of `console.log` to reflect game state
- Tracking and persisting score across multiple rounds using variables in an outer scope
- Using `disabled` to end interaction once a win condition is met
- Structuring win/lose/tie logic with nested conditionals
- Working with Git branches: creating a feature branch, merging it into `main`, and cleaning up afterward
## Built with
- HTML5
- CSS3 (Flexbox)
- JavaScript (DOM manipulation, event listeners)
## Ideas to improve
- Animating the round result instead of just swapping text
- Adding a "Play Again" button to reset the score without reloading the page
- Highlighting the winning/losing choice visually
- Keyboard support for selecting rock/paper/scissors
- Making the layout responsive for smaller screens
